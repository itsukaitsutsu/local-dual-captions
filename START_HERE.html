01 / GET STARTED

Your GPU. Your choice.

Extract the full project to a stable folder, such as C:\LocalDualCaptions. Complete the prerequisites below, then double-click Setup.cmd or use the command shown.

WINDOWS 10 / 11 X64

Choose a recognition backend

INSTALL ONCE / BEFORE COMPILING
  • Python 3.11 x64 with the py launcher; VC++ x64 Redistributable.
  • Git for Windows and CMake in PATH.
  • Visual Studio 2022 Build Tools → Desktop development with C++ + Windows SDK.
  • Current AMD/other Vulkan driver + LunarG Vulkan SDK, including glslc. Reopen your terminal after installing.

Compiler tools and SDKs can be several GB. Already have a compatible whisper-server.exe? Use the reuse option below and skip compiling.

POWERSHELL / FROM THE PROJECT FOLDER
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Setup.ps1 -Backend Vulkan

An additional ~147 MiB Japanese→English translator and Python dependencies are downloaded once. Partial model downloads resume; SHA-256 checks reject corrupt files. No API key or account required.

Then connect Chrome

1

Finish setup; start the runner

Run Start.cmd. Keep the terminal open and wait for startup. Copy the private pairing key, also saved in data\pairing-key.txt.

2

Load the extension folder

Open chrome://extensions → Developer mode → Load unpacked → choose the project's extension folder, not the ZIP or project root.

3

Pair once; caption your tab

Open the extension. Paste the key and click Check connection. Play Japanese audio on an HTTP/HTTPS webpage, then click Caption this tab.

4

Read both lines; adjust the style

Japanese appears first, then English. Drag the header to move captions. Choose text size, opacity, position, or an English-only view in the popup.

5

Stop explicitly

Click Stop captions or the overlay's ×. Navigation/closing the tab also stops capture. Ctrl+C in the runner terminal stops both local servers.

Actually test it offline. Run Offline-Test.cmd, open its local player in Chrome, and choose a downloaded Japanese media file. Start captions, then disconnect Wi-Fi. This avoids confusing a buffering video stream with a caption-engine problem.
Already have your GGML model and a Vulkan/CUDA whisper-server.exe?

Reuse both. Keep the executable's backend DLLs beside it. Python + the VC++ runtime are still needed, but this path skips Git/CMake/SDK source compilation. Use a server with /health, /inference, --request-path, and verbose_json support (reference version: whisper.cpp v1.9.5).

powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Setup.ps1 -Backend Vulkan -ServerPath "C:\whisper\whisper-server.exe" -ModelPath "C:\Models\ggml-large-v3-turbo.bin"

For NVIDIA, supply a CUDA-enabled executable and use -Backend CUDA. The flag cannot turn a CPU binary into a GPU binary. Details and offline translation-folder reuse are in README.md.

What does Whisper actually do?

It turns audio into a spectrogram—a representation of frequencies over time. A Transformer encoder analyzes the sound; a decoder predicts text tokens. The Turbo variant has a smaller decoder than large-v3. This app uses it for Japanese speech recognition, not translation.

Why not put the GGML file directly in Chrome?

A GGML file is model data, not a browser plugin. A WebAssembly implementation is possible, but a large model brings substantial memory and compute constraints. The local native helper is a practical way to use your existing AMD/Vulkan or NVIDIA/CUDA setup.

Meaning, not word substitution—but not perfect understanding. OPUS-MT translates phrases, not individual dictionary entries. The app retranslates short rolling utterances as more words arrive. It is not a document-aware LLM; implied subjects, idioms, names, and negation can still be wrong. Read the original alongside the translation.

03 / SET EXPECTATIONS

Offline doesn't mean instant.

Caption delay comes from audio buffering, model inference, queueing, and translation. There is no hardware-independent latency guarantee.

NEAR-LIVE / CHUNKED
PROFILEWINDOW CAPPAUSE GATE
Fast3.2 seconds440 ms
Balanced5.5 seconds640 ms
More context8.5 seconds840 ms

A pause may finish a chunk earlier. These are buffer settings, not end-to-end benchmark results. Shorter windows can incur more fixed encoder work. On weak CPUs, even Turbo may be too slow for live audio.

Watch RTF

Processing time ÷ new audio duration. Sustained RTF above 1 means the engine cannot keep up.

No unlimited backlog

One active + two pending jobs. Overload skips old pending chunks with a warning; words may be lost.

Media still needs to arrive

Local AI cannot caption audio that a buffering website has not played yet.

Player restrictions apply

DRM and native video/iframe fullscreen may block audio or hide the overlay. Try theatre mode.
